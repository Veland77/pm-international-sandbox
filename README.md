# PM International — Sandbox

A test environment for the PM International business-system redesign project. This is **not** connected to any real PM system or real data. Everything here is fictional, built to demonstrate how new modules and workflows could work before anything is built for production.

## What this is

- A small Node.js web app with a SQLite database.
- Fake/synthetic test data only (products, suppliers, orders, users) — see `seed/`.
- Deployed automatically to Render on every push to `main`.
- Reachable at `sandbox.litleholm.no`.

## Project structure

```
/src            application code
/src/routes     one file per feature area (keep these small)
/src/db         database connection + schema
/seed           scripts that generate fake test data
/tests          automated tests
CLAUDE.md       house rules for AI-assisted development (read this first)
render.yaml     Render deployment config
```

## Running locally

```
npm install
npm run seed     # creates data/sandbox.db with fake data
npm run dev      # starts the app on http://localhost:3000
```

## Deployment

Render watches this repo's `main` branch and redeploys automatically on push. Nothing needs to be done manually. Live URL: https://sandbox.litleholm.no

## Rules

1. No real PM International data — ever. Only fictional data generated by the seed scripts.
2. Every screen in the sandbox shows a visible "SANDBOX — TEST DATA" banner so it's never mistaken for a real system.
3. New features start as a short written plan (see CLAUDE.md), reviewed before any code is written.
